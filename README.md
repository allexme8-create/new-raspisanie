# 🗓️ Расписание лицея — веб-приложение (Frontend + Backend)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/allexme8-create/new-raspisanie)

Веб-приложение для публикации расписания уроков лицея.

- **Администратор** через админ-панель загружает два файла расписания
  (`Учителя` — в ячейках фамилии учителей с кабинетами, `Предметы` — названия предметов).
  Файлы можно загрузить с устройства.
- **Ученики, родители и учителя** видят расписание по классам, по учителям,
  свободные кабинеты и «⭐ Избранное» — без сведений о загруженных файлах и лишних счётчиков.
- В расписании показываются дата/время последнего обновления, время каждого урока
  и текущий номер урока с количеством минут до звонка.
- Администратор может загрузить отдельную таблицу звонков и выбрать классы второй смены.
- Интерфейс адаптирован под **мобильные устройства** (нижняя навигация, карточный вид).
- Установка не требуется — всё работает в браузере через сервер.

## Быстрый запуск (локально)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# задайте пароль администратора (по умолчанию: admin123)
export ADMIN_PASSWORD="мой-секретный-пароль"   # Windows: set ADMIN_PASSWORD=...

python app.py                    # или: uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте в браузере:

| Страница | Адрес |
|---|---|
| 📅 Клиент (расписание) | http://localhost:8000/ |
| 🛠️ Админ-панель | http://localhost:8000/admin |
| 📄 Документация API | http://localhost:8000/api/docs |

### Docker

```bash
docker build -t raspisanie .
docker run -p 8000:8000 -e ADMIN_PASSWORD="секрет" -v raspisanie_data:/app/backend/data raspisanie
```

Том `raspisanie_data` сохраняет загруженные файлы между перезапусками.

## Работа администратора

1. Откройте `/admin`, введите пароль (`ADMIN_PASSWORD`).
2. Загрузите **оба файла расписания** — тип («Учителя»/«Предметы») определяется
   автоматически по содержимому:
   - 🖱️ перетащите `.xls/.xlsx/.xlsm/.xml/.csv` в зону загрузки или выберите файлы на устройстве.
3. При необходимости загрузите отдельную таблицу **расписания звонков** (`.csv`, `.xls`,
   `.xlsx`, `.xlsm` или `.xml`). В ней должны быть блоки по четыре столбца на смену:
   `День недели; Урок; Начало; Окончание`. Для CSV принимаются кодировки UTF-8 и Windows-1251;
   время можно указать как `8.25` или `08:25`.
4. В блоке **«Классы второй смены»** отметьте нужные классы и нажмите «Сохранить».
   Нумерация уроков во второй смене начинается с 1, время берётся из соответствующего блока
   расписания звонков.
5. После сохранения расписание сразу доступно посетителям. Они видят только дату и время
   обновления, время уроков и индикатор текущего урока — без имён файлов и счётчиков классов,
   учителей и кабинетов.

Для быстрой проверки в каталоге `samples/` лежат два тестовых файла расписания:
`Пример_учителя.xlsx` и `Пример_предметы.xlsx`. Автоматические тесты запускаются так:
`python -m unittest discover -s tests -v` и `node tests/test_frontend.cjs`.

## API (кратко)

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/schedule` | публично | Сетки расписания, звонки, смены и дата обновления |
| GET | `/api/status` | публично | Готовность данных и дата обновления |
| POST | `/api/admin/login` | — | `{password}` → `{token}` |
| GET | `/api/admin/status` | Bearer | Статус файлов и список классов |
| POST | `/api/admin/upload` | Bearer | multipart `files` — файлы учителей/предметов |
| POST | `/api/admin/bell-schedule` | Bearer | multipart `file` — таблица расписания звонков |
| PUT | `/api/admin/settings` | Bearer | `{second_shift_classes: [...]}` — классы второй смены |
| POST | `/api/admin/fetch-yandex` | Bearer | `{url}` — скачать файл расписания с Яндекс.Диска |
| DELETE | `/api/admin/file/{kind}` | Bearer | Удалить `teachers`, `subjects` или `bell_schedule` |

## Формат файлов расписания

Формат полностью совпадает с исходным HTML-приложением:

- строка заголовка содержит названия классов, начиная с `5а` (`5а 5б 5в … 11б`);
- в первом столбце — дни недели `Пн Вт Ср Чт Пт Сб`, рядом — номер урока;
- ячейка: `Алгебра, Геометрия (12, 14)` — значения через запятую, кабинеты в скобках;
- в файле «Учителя» вместо предмета — фамилия учителя, например `Иванова ИИ (305)`;
- служебные ячейки: `Классный час`, `СФУ`, `Экскурсия` (без кабинета).

## Конфигурация

| Переменная окружения | По умолчанию | Назначение |
|---|---|---|
| `ADMIN_PASSWORD` | `admin123` | Пароль входа в админ-панель |
| `PORT` | `8000` (в Docker — `7860`) | Порт HTTP-сервера |
| `BACKUP_GH_TOKEN` | — | GitHub-токен для автобэкапа расписания |
| `BACKUP_GH_REPO` | — | Репозиторий бэкапа, напр. `allexme8-create/new-raspisanie` |
| `BACKUP_GH_BRANCH` | `schedule-data` | Ветка бэкапа (создаётся автоматически) |
| `BACKUP_GH_PATH` | `backup/state.json` | Путь файла состояния в репозитории |

Если заданы `BACKUP_GH_TOKEN` и `BACKUP_GH_REPO`, после каждой загрузки файлов админом
расписание автоматически коммитится в GitHub, а при старте сервера с пустым диском —
восстанавливается оттуда. Это спасает на бесплатных хостингах с эфемерной ФС.

> ⚠️ Перед публикацией в интернете обязательно смените пароль администратора
> и раздавайте сайт по HTTPS (например, через nginx/Caddy).
