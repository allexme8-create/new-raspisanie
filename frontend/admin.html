Как подключить почту через OAuth — без SMTP_PASSWORD

  1. Откройте сайт по постоянному HTTPS-адресу. В настройках хостинга задайте PUBLIC_BASE_URL — адрес сайта без пути, например https://school.example.ru.
  2. Создайте веб-приложение у Яндекса или в Mail.ru. Укажите Redirect URI: https://ВАШ-ДОМЕН/mail-oauth/callback, заменив https://ВАШ-ДОМЕН на тот же PUBLIC_BASE_URL. Для Яндекса выберите право mail:smtp; для Mail.ru — userinfo и mail.imap.
  3. В секретах хостинга задайте ID и секрет приложения: YANDEX_OAUTH_CLIENT_ID и YANDEX_OAUTH_CLIENT_SECRET либо MAILRU_OAUTH_CLIENT_ID и MAILRU_OAUTH_CLIENT_SECRET. Там же задайте MAIL_OAUTH_ENCRYPTION_KEY — сгенерируйте его на сервере командой python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())". Секреты не отправляйте в чат и не сохраняйте в репозитории.
  4. Перезапустите сервер. Ниже введите e-mail отправителя, нажмите кнопку нужного провайдера и разрешите доступ в открывшейся вкладке. Дождитесь сообщения об успешном подключении.

Mail.ru запрашивает mail.imap, которое может включать чтение почты и требовать согласования у провайдера. В предпросмотре, если подключение не завершается, откройте админку в отдельной вкладке на том же адресе сайта. Подробнее — в DEPLOY.md.

Для SMTP по паролю потребуется SMTP_PASSWORD в настройках сервера. При переключении на него или настройки сервера OAuth-подключение будет удалено.

Создайте директора или заместителя. Логин (e-mail) и временный пароль отправляются на указанную почту; при первом входе пароль нужно сменить. При удалении пользователь получает уведомление, доступ прекращается, а история задач сохраняется без его e-mail. Для создания и удаления требуется настроенный SMTP.

Конструктор расписания

Создавайте черновик независимо от опубликованного расписания. Для проверки и подбора сначала загрузите расписание звонков.

Загруженные файлы

Нужны два файла расписания: «Учителя» (в ячейках фамилии учителей с кабинетами) и «Предметы» (в ячейках названия предметов). Тип файла определяется автоматически при загрузке.

Загрузить файлы с устройства

📂 Перетащите файлы сюда или нажмите, чтобы выбрать

Форматы: .xls, .xlsx, .xlsm, .xml, .csv. Можно сразу оба файла — тип определится автоматически.

Расписание звонков

Загрузите отдельную таблицу со временем начала и окончания уроков. Поддерживаются CSV, XLS, XLSX, XLSM и XML. Для смен используйте два блока по четыре столбца: «День недели», «Урок», «Начало», «Окончание».

Классы второй смены

Отметьте классы, которые учатся во вторую смену. Для них номера уроков начинаются заново с первого и берётся время из блока «2 смена».

Загрузить по ссылке Яндекс.Диска

Вставьте публичную ссылку на файл (например https://disk.yandex.ru/i/…) — сервер скачает файл и применит его. Требуется доступ сервера к интернету.
