Вход для администратора

Пользователи руководства

Укажите e-mail как логин и выберите роль. Пароль создаётся автоматически; передайте его пользователю безопасным способом. При первом входе пользователь сменит пароль. Администратор может показать текущий пароль или создать новый. Письма не отправляются.

Доступ к паролям имеют администраторы: используйте HTTPS и надёжный пароль администратора.

Конструктор расписания

Создавайте черновик независимо от опубликованного расписания. Для проверки и подбора сначала загрузите расписание звонков.

Загруженные файлы

Нужны два файла расписания: «Учителя» (в ячейках фамилии учителей с кабинетами) и «Предметы» (в ячейках названия предметов). Тип файла определяется автоматически при загрузке.

Загрузить файлы с устройства

📂 Перетащите файлы сюда или нажмите, чтобы выбрать

Форматы: .xls, .xlsx, .xlsm, .xml, .csv. Можно сразу оба файла — тип определится автоматически.

Расписание звонков

Загрузите отдельную таблицу со временем начала и окончания уроков. Поддерживаются CSV, XLS, XLSX, XLSM и XML. Для смен используйте два блока по четыре столбца: «День недели», «Урок», «Начало», «Окончание».

Классы второй смены

Отметьте классы, которые учатся во вторую смену. Для них номера уроков начинаются заново с первого и берётся время из блока «2 смена».

Сначала загрузите расписание уроков.

Загрузить по ссылке Яндекс.Диска

Вставьте публичную ссылку на файл (например https://disk.yandex.ru/i/…) — сервер скачает файл и применит его. Требуется доступ сервера к интернету.
